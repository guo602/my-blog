## 艰苦奋斗时期

* 1907年 延一井
    ```

    中国陆上第一口工业化开采的油井，中国大陆不依赖外国技术、独自钻凿成功的第一口油井。
    
    位于陕西省延安市延长县。

    ```
* 1959年 大庆油田
* 1967年6月 海1井
    - 海上第一口油井
* 代表人物
    1. 铁人 王进喜
    2. 海油青年 刘桂芝
        - 日本电焊大赛冠军
        - 全国劳模
* 下海找油-渤海勘探队
    * 用慈溪的小船装上勘探设备
    * 64名海军
